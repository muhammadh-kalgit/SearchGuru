# SearchGuru

SearchGuru is a simple image search website. You type a word, press Search, and the results show in a grid.

## Features

- Search bar with a Search button
- Results shown in a responsive grid
- Search bar is big on large screens and shrinks on small screens
- Sticky header: the title and search bar stay at the top while you scroll
- Clean light design with cream and teal colors
